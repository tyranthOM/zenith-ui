# ✨ Zenith UI

> Modern, lightweight UI component primitives and sleek interactive motion system.

## Overview
Zenith UI is an accessible design kit built with modern glassmorphism, micro-interactions, and fluid CSS variables.

## Components
- 🔘 Dynamic Buttons with tactile haptic states
- 🗂️ Floating Glassmorphic Modals & Drawers
- 📊 Responsive Data Badges & KPI metrics
